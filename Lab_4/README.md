# Лабораторна робота №4: Аспектно-орієнтоване програмування (AOP) у Spring Boot

Цей проєкт демонструє використання **Aspect-Oriented Programming (AOP)** у Spring Boot 3 на Java 17.

---

## ❓ Простими словами: Що таке AOP і навіщо воно потрібне?

У звичайному програмуванні, якщо вам потрібно виміряти час виконання методу, перевірити права доступу та записати лог дій, ви змушені писати цей код усередині кожного методу. Це засмічує бізнес-логіку.

**AOP (Аспектно-орієнтоване програмування)** дозволяє винести всю цю «службову» логіку (безпеку, таймери, аудит) в окремі класи — **Аспекти**. Методи залишаються чистими, а Spring сам «підхоплює» їх і виконує потрібний додатковий код у потрібний момент.

## 🏗 Як влаштований проєкт (Архітектура)

Усі класи проєкту розділені за трьома основними блоками:

```text
src/main/java/org/example/lab4/
├── annotation/             # 1. АНОТАЦІЇ ("Наліпки" / Ярлики)
│   ├── RequireRole.java    # Маркер: "Цей метод вимагає певної ролі"
│   ├── ExecutionTimer.java # Маркер: "Виміряти час роботи цього методу"
│   └── AuditLog.java       # Маркер: "Записати в журнал подій результат цього методу"
│
├── aspect/                 # 2. АСПЕКТИ ("Перехоплювачі" / Логіка)
│   ├── AccessControlAspect.java # Перевіряє права ДО запуску методу (@Before)
│   ├── ExecutionTimerAspect.java# Заміряє час ДO та ПІСЛЯ запуску методу (@Around)
│   └── AuditLogAspect.java      # Записує аудит ПІСЛЯ УСПІШНОГО завершення (@AfterReturning)
│
├── service/                # 3. БІЗНЕС-ЛОГІКА
│   └── OrderService.java   # Сервіс створення замовлень із маркованими методами
│
└── Lab4Application.java   # 4. ГОЛОВНИЙ КЛАС
                            # Запускає 3 сценарії тестування при старті програми
